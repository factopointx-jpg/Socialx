SOCIALX VERSION 1
1. Create a Supabase project.
2. Open SQL Editor and run schema.sql.
3. Create Storage bucket: post-media (Public for this starter).
4. Open index.html and replace SUPABASE_URL and SUPABASE_KEY.
5. Upload index.html to GitHub.
6. Deploy the GitHub repository with Cloudflare Pages.
Never put a Supabase service-role/secret key in this file.
